两种方式二选一：
① 推荐：在 GitHub 生成一个 Personal Access Token（勾选 repo + workflow 权限）发给我， 我自动建仓库、传代码、触发构建、取回 IPA —— 你什么都不用做。
② 自己动手（10 分钟）：按下述步骤操作。

方式②：自己动手步骤

  1. 登录 github.com → 右上角 + → New repository，名字填 weiliao-ios， 勾选 Add a README，创建。
  2. 仓库页面 → Add file → Create new file，文件名输入： .github/workflows/ios.yml（注意是两个斜杠），把本页最下方文本框的内容复制进去，Commit。
  3. 仓库页面 → Add file → Upload files，把解压出来的 project.yml、scripts/、Weiliao/ 里的所有文件拖进去上传（保持目录结构，github 网页端上传文件夹需用浏览器拖拽文件夹）。
  4. 上传完成后进入 Actions 标签 → 选 "Build iOS unsigned IPA" → Run workflow → 等 5~8 分钟。
  5. 构建完成后在该次运行页面底部 Artifacts 下载 Weiliao-unsigned-ipa，解压即得未签名 IPA。

IPA 怎么装到手机

IPA 必须有苹果签名才能安装（工具无法伪造签名）：
① 免费 Apple ID：电脑装 Sideloadly 或 爱思助手，手机连电脑签名安装，7 天有效，到期重签；
② 688 元/年开发者账号：走 TestFlight 分发，长期有效（需先在开发者后台登记 Bundle ID：cn.yinghemingyu.weiliao）。
